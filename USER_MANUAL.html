CFS App ユーザーマニュアル

一般配布版 / 更新日: 2026-06-22

このマニュアルは、CFSアプリをローカル環境で共有・運用するための一般化された説明書です。特定プロジェクト名には依存しません。

1. アプリの目的

CFS Appは、照明制御、デバイス割当、シーン、スイッチ、PIR/QSM、Backlight、HVACなどの情報を整理し、CFSとして確認・出力するためのローカルWebアプリです。

作業データはアプリフォルダ内の data/projects.json と data/trash/trash.json に保存されます。

2. 起動方法

  1. ZIPを任意のフォルダへ展開します。
  2. Node.js LTSをインストールします。
  3. START_CFS_APP.bat をダブルクリックします。
  4. 初回のみ依存関係のインストールが実行されます。
  5. ブラウザで http://localhost:3000 を開きます。
既に別のアプリが3000番ポートを使用している場合、起動ログに表示される別ポートのURLを開いてください。

3. 基本ワークフロー

  1. Projectを作成または選択します。
  2. Locations / Areasで部屋・エリアを登録します。
  3. Fixturesで照明器具情報を登録します。
  4. Circuitで回路、調光方式、Detail、Areaを登録します。
  5. Device Assignでデバイス、ゾーン、CCI/CCO、DALIアドレスを割り当てます。
  6. Scene / Area Scene / Switch / Command / Backlightを設定します。
  7. CFSタブで最終的な並び、Detail、Area Address、Programming Nameを確認します。
  8. 必要に応じてExcelやJSONを出力します。

5. CFSタブの確認ポイント

  • Area Highlightを使い、同じAreaの行まとまりを確認します。
  • Area Addressが重複していないことを確認します。
  • Programming Nameが標準形式になっていることを確認します。
  • DALIはGroup/AddressまたはLine/Group/Addressの並びを確認します。
  • HighlightsのLinked ValuesをONにすると、Scene / Switch / Commandなどと連動しているCFSの機能セルが薄いシアンで表示されます。
  • Link Mapは、CFS表に常時線を重ねず、必要な時だけ開く連動診断ビューです。Overviewは紙面型の放射状マップで、タブやカテゴリの大きなノードをクリックすると、その詳細ノードが周囲へ展開されます。詳細ノードをクリックすると、紙面上と右側パネルで接続先を確認できます。Current Links、All Rules、Warningsでは、現状リンク、期待ルール、ノード詳細、警告、スナップショット署名を確認します。
  • WarningsにStale HVAC targetが出た場合は、旧HVAC IDをArea Sceneが参照している可能性があります。復旧候補が一意に判定できる場合はRepair Stale HVACで現行HVAC targetへ置換し、復旧直後のRepaired Linksハイライトで該当セルを確認します。
  • CCIは動作の起点としてSwitch/Command側の列に表示し、CFSのベース行には表示しません。CCOは出力対象としてCFSのベース行に表示します。
  • HVACとBacklight Logicは照明系の並びとは別扱いとして確認します。

6. データ保存とバックアップ

プロジェクトデータは data フォルダ内に保存されます。アプリを更新するときは、このフォルダを削除または上書きしないでください。

  • 通常バックアップ: data フォルダをコピーします。
  • 共有前バックアップ: Project画面のExport、またはJSONバックアップを保存します。
  • 共有DBで保存競合が出た場合: 画面を閉じずに、表示された確認で上書き、サーバー版の再読込、JSONバックアップ出力を選択します。上書きは、確認時に表示されたサーバー更新時刻と保存時点の更新時刻が一致する場合だけ実行されます。
  • 復旧: バックアップした data/projects.json を戻します。

7. 共有とアップデート

フルZIP

初回配布用です。アプリ本体と現在の data フォルダを含みます。別のPCへ同じ状態を渡す場合に使います。

アップデートパッチZIP

更新用です。アプリ本体だけを含み、data フォルダは含みません。既存プロジェクトを残したまま更新する場合に使います。

既存環境を更新するときは、フルZIPで上書きせず、データなしのアップデートパッチZIPを使用してください。
