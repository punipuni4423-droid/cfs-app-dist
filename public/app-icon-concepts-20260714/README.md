# CFSアプリアイコン候補 2026-07-14

前回の機能アイコン寄りの候補から、アプリ本体のアイコンとして使いやすい方向へ作り直したSVG候補です。

## 方針

- アプリ本体の顔になることを優先
- favicon / タスクバー / 配布パッケージで潰れにくいことを優先
- CFSの既存UIに合わせて `#007B7E`、白、薄いグレー、濃いグレーを基調にする
- 表、回路リンク、照明設計の要素は残すが、機能アイコンの説明っぽさは減らす

## 候補

- `01 Teal Sheet`: 本命。ティール背景 + 白いCFSシート
- `02 Circuit C`: 文字なしのCマーク + 回路
- `03 CFS Badge`: CFS名を強調するバッジ
- `04 Folded Grid`: 書類/Excel感が強い
- `05 Linked Tiles`: データ連携/統合感
- `06 Slate Pro`: 暗色ベースの業務アプリ感
- `07 C Mark`: 太いCマークでfavicon向き
- `08 Room Grid Mark`: 部屋・回路・照明設計寄り
- `09 Light Circuit`: 照明設計感が強い
- `10 Minimal CFS`: シンプルな白系CFSロゴ

採用候補が決まったら、その案をもとに以下を作れます。
