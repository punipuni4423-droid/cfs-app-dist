# CCOによるOn/Off照明の割付

Device AssignのCCO行で「CCO assignment mode」を「On/Off Lighting (external relay)」にすると、CircuitタブのOn/Off回路を選べます。「Dry Contact」は既存の接点用途です。用途を切り替える際は、現在の割付を解除する確認を表示します。

CCOは外部DC24V回路を接点で開閉し、その先の外部リレーで照明のAC負荷を開閉します。CCO自体からDC電源は供給されません。外部リレーの1A・3A・15Aなどの定格は外部設計で管理し、CFSへリレーを器具として登録する必要はありません。

既に4S等へ割り当てた回路をCCOで選ぶと、元出力からの移設を確認します。確定したときだけ、元の全器具展開行を解除してCCOへ移します。混合器具の照明名称は元のDevice Assign Detailを保持します。CCOから4Sへ戻すときは、CCO側をClearしてから4Sへ割り当てます。

「+」で同一CCOに最大5回路をまとめられます。同一出力なのでそれらは一緒にOn/Offします。既存の束ね出力の主回路を他のCCOへ移す場合は、先に束ねを解除してください。追加回路を移す場合は、その回路だけ元の束ねから外します。

CFSとCFS Excelには物理出力CCO、Type On/Off、回路番号、Detail、合計VAを表示します。Scene等は従来のCircuitを対象にするため、接点用CCOの設定行を二重に作りません。Dry Contact、CCI、DALI・位相・PWMの従来の設定は維持します。

照明CCOを含む案件は、この機能に対応した配布版で編集・保存してください。旧版での編集・保存は、新しい割付情報の保持を確認できないため避けてください。
