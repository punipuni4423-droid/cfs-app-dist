起動に必要な条件とファイル

分類必要なもの説明
OSWindows PCLAUNCH_CFS_APP.cmd、START_CFS_APP_CONSOLE.bat、ショートカット作成スクリプトはWindows向けです。
ネットワークDatabase接続とApp Update時のインターネット接続最新版の配布Zipはビルド済みruntimeとNode.js runtimeを同梱します。Git管理ZipではPortableGitも同梱します。Database版ではSupabaseとMicrosoftログインへの接続が必要です。
認証Microsoftアカウント共有データベース版では、管理者が登録したメールアドレスでログインします。プロジェクトが表示されない場合はログイン状態と権限を確認します。
実行ファイルLAUNCH_CFS_APP.cmd通常起動用です。ダブルクリックすると起動準備を行い、ブラウザでCFSを開きます。
補助起動START_CFS_APP_CONSOLE.batログ確認や手動起動に使います。通常起動で開かない場合の診断用です。
ショートカットCREATE_DESKTOP_SHORTCUT.vbsデスクトップとスタートメニューにCFS Appショートカットを作成します。作成後のメッセージで参照先フォルダを確認できます。
Database設定cfs-public-supabase.envDatabase版に必要な公開設定です。Service Role Keyやクライアントシークレットは入れません。
同梱必須runtime、.cfs-runtime、app、public、scriptsビルド済みruntime、Node.js runtime、アプリ本体、起動補助スクリプトです。Git管理Zipでは .cfs-runtime\git も含みます。
同梱しないものdata、.env.local、生の .next、ルートの node_modules配布Zipではユーザーデータ、秘密情報、開発用ビルド成果物は含めません。通常Zipは .git を含めず、Git管理ZipのみApp Update用に含めます。
OneDriveやネットワーク共有フォルダ上で直接起動すると、同期やファイルロックで不安定になることがあります。まずローカルフォルダへ解凍して起動してください。

起動手順

1. Zipを解凍
任意のローカルフォルダへ展開します。フォルダ名に日本語やスペースがあっても動作しますが、深すぎるパスは避けます。
2. 起動
LAUNCH_CFS_APP.cmd をダブルクリックします。通常は利用者PCでnpm installやNext buildを行いません。
3. ブラウザ表示
準備が完了すると http://localhost:3014 などのローカルURLが開きます。同じポートに別フォルダの古いCFSがいる場合は、自動で空きポートへ退避します。
4. ログイン
Database版ではMicrosoftログインを行います。ログイン後に権限があるプロジェクトが表示されます。
5. ショートカット
必要に応じて CREATE_DESKTOP_SHORTCUT.vbs を実行します。新しいZipへ入れ替えた時は、古いショートカットを削除して新しい解凍フォルダから作り直します。

起動状況は artifacts\startup\latest-status.txt と同フォルダの最新ログで確認できます。

Remarksタブ(2026-09-07追加)

プロジェクト単位の申し送りメモを管理するタブです。親タブは Area / Fixture / Room Type / Remarks の順に並びます。メモは縦に並び、タイトル・本文・任意の表を持てます。

No名称機能
1Remarksタブプロジェクトのメモ一覧へ移動します。
2Edit / PreviewEditは入力しやすい広い列幅を固定し、Previewだけ内容に合わせて列幅を調整します。
3Add Remarkメモを追加します。
4ドラッグハンドルメモの並び替えを行います。メモ右上のアイコンで複製・削除ができます。
5Tableチェックとプリセットメモに表を付けます。オフにしても列と行の内容は保持され、再度オンにすると元に戻ります。プリセットは Flow(Table有効化時の既定)= Trigger / Condition / Action / Result、Variable = Variable / State / Action、Rationale = Target / Value / Rationale、Legend = Symbol / Meaning。
6Add Column / Add Row列や行を追加します。見出し横の−で列を、行末の−で行を削除し、セルは直接入力します。Editの列は短い値や空欄でも広いままです。長い文章や見出しは列内で折り返し、セル内では改行も入力できます。
7Excel ExportRemarksだけを {Project}_Remarks.xlsx に出力します。Edit・Previewのどちらからも使用でき、保存前の編集内容も含みます。メモが0件のときと出力中は無効です。ファイル名の空白と使用できない記号はアンダースコアに置き換わります。
プリセットボタンを押すと、その表の見出しと行が新しいプリセットに置き換わります。作成済みの表(以前の日本語列名を含む)は、読み込み・保存・複製だけでは変わりません。

Edit・Preview とも白背景と薄い罫線を保ちます。Previewは短い列をコンパクトに保ち、長文列はカード内の余白を使い切ってから折り返します。長文列が複数ある場合は、内容量に応じて幅を配分します。各列の最小幅が画面幅に収まらない場合は、各ノートの表の内側を横にスクロールできます。Editは入力中も広い列幅が固定されます。

Remarksタブの Excel Export は、All Roomsに含まれるRemarksと同じ内容・書式の1シートを出力します。Excelも短い列を保ちながら長文列に残りの幅を配分し、読みやすい全体幅を超える長文を折り返します。画面サイズやEdit列幅には依存せず、同じシート内の列幅は共通です。Tableがオフの表は保持されますが出力されません。

CFSタブの Excel Export → All Rooms では、各Room Typeのシートに続けて Remarks シートを同梱します。メモの順番でタイトル・本文(改行を保持)・有効な表を出力し、表は内容に応じた列幅と折り返し、罫線を使います。Tableがオフの表は出力しません。メモが0件ならシートを省略します。同名のRoom Typeがある場合は、Remarks側を Remarks (2) などの連番名にします。

This Room Type は従来どおり現在のRoom Typeだけを出力し、Remarksは含めません。Sub Window・Fixed WindowからのAll Rooms出力にも、同じプロジェクトのRemarksが含まれます。

CFS編集モード(Edit)とリンク・一括変更(2026-09-08更新)

CFSタブの「Edit」トグルに、設定変更(Setting)・リンク(Link / Unlink)・Low End / High End 編集の入口を統合しました。Editは既定でオフで、オフの間は編集用のチェックボックスや編集ボタンは表示されません。View(閲覧のみ)ではEdit自体を押せません。

Editトグルと設定(Setting)への入口

No名称機能
1EditトグルCFS上の編集入口をまとめてオン/オフします。オンの間は対象列(Switch / Command / Scene)に列チェックと鉛筆が表示されます。
2列チェックボックス見出し最下行でリンク対象の列を選択します。チェックだけでは設定画面は開きません(名前セルや鉛筆とは領域が分かれています)。
3鉛筆・名前セル最下行の鉛筆はその列のSetting画面(オーバーレイ)を直接開きます。名前セルのクリックでも開けます。保存経路は各タブのSettingと同じです。
4Link / Unlinkチェックした列同士をリンク/リンク解除します(詳細は下記)。
InspectionModeと同時にオンにできますが、InspectionMode中はSettingとリンクの操作は使えません(Low End / High Endの編集のみ可能です)。

複数条件の選択メニュー(結合セル)

設定先が1つの名前セルは、クリックすると直接Settingが開きます(1)。同じスイッチ・同じボタンに複数の条件(Press / Double Tapなど)があり表示が結合されているセルでは、クリックすると条件の選択メニュー(2)が開き、選んだ条件のSettingへ進みます。Escapeキーまたはメニューの外側クリックで取り消せます(値は変わりません)。

最下行の鉛筆はPress / Double Tapそれぞれに用意され、その条件のSettingを直接開きます。

リンク(Link / Unlink)の拡張

No名称機能
1・2列チェックボックスリンクしたい列をチェックします。SwitchとCommandは混在して選択できます。
3選択数とLink / Unlink2列以上選ぶとLinkが有効になります。リンク済み列を選んでUnlinkすると、選んだ列だけがリンクから外れます。
4・5Link記号リンク中の列は見出し最下行のLink A / Link B…と幅4pxの境界線で表示されます。結合セルの内部では縦線が途切れます。記号はSwitch / Command / Scene共通の1系列です。
項目内容
リンクできる組み合わせSwitch同士、SwitchとCommandの混在、Scene同士。SceneとSwitch / Commandの混在はできません(片方を選ぶともう一方のチェックが無効になり、理由が表示されます)。
リンク後の動作リンクした列のどれかを保存すると、他の列にも同じ設定が反映されます。Switch / CommandではFunction設定とBacklight条件、SceneではArea Scene選択・個別上書き値・Backlight条件が同期されます。
同期されないものスイッチ番号・名前・ボタン・Trigger Condition、SceneのPhase / Scene Type / Detail / Trigger Conditionなどの識別情報。Backlightの配線先(Target)も列ごとに保持されます。
コピー・複製Switch / Command / Sceneのコピー、Room Typeの複製では、リンクは引き継がれません。
Sceneタブに標準で用意されるFrom PMS Scene列(デフォルト2本)も、リンク可能なScene列として選択肢に表示されます。意図しない列をリンクしないよう、Linkを押す前に選択内容を確認してください。
