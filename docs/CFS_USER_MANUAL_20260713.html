1. はじめに・起動

  1. 共有ZIPをローカルフォルダーへ展開します。
  2. LAUNCH_CFS_APP.vbs を実行します。ターミナルは表示されず、起動処理はバックグラウンドで実行されます。
  3. Node.js 20以降が未導入または旧版の場合は、公式LTS版をアプリ専用の .cfs-runtime フォルダーへ自動導入し、公式SHA-256値で確認してから使用します。管理者権限やWindowsのシステム設定変更は不要です。
  4. 初回は依存関係の導入とビルドを行い、完了後にブラウザーが自動で開きます。失敗時は artifacts/startup/latest-status.txt と同フォルダーのログを確認します。タブレットはプロジェクト選択画面に表示される TABLET URL を使用します。
データの保存先: 下書き・表示設定はそのPCのブラウザーに保存されます。保存済みプロジェクトとRevisionは、導入環境の設定によりPC内の data フォルダー、またはSupabaseを設定済みの共有データベースへ保存されます。共有ZIPには既存プロジェクトデータを含めません。
ネットワーク公開: タブレット接続のためCFSはPCのローカルネットワークから開けます。信頼できない機器が同じネットワークにある場合は、PCのファイアウォールでアクセスを制限してください。

4. CFSを完成させる標準手順

  1. Projectを作成し、必要なAreaとFixtureを登録します。
  2. Room Typeを作成します。実際の部屋番号ではなく、共通ロジック単位で作成します。
  3. CircuitでDesigner #、Dimming Type、Area、Fixture、数量、Detailを入力します。
  4. Device Assignで回路・ゾーン・DALI・CCI/CCO・HVACを機器へ割り当てます。
  5. Area Sceneでエリアシーンの値、SceneでRoom SceneとArea Scene選択を設定します。
  6. Switch / Command / Backlightで操作ボタン、トリガー、バックライトロジックを設定します。
  7. PDUで機器数量、Fixture VA、PDU収支、必要ブレーカーを確認します。
  8. CFSで全体表を確認し、必要ならフィルター・列表示・Excel Exportを使用します。
  9. Save Revisionで改訂を保存します。更新箇所の確認には Highlight Updates を使います。
  10. 検査が必要な場合は InspectionMode を実施し、終了時にRevisionとして保存します。
設計の順序は「マスター → 回路 → 割当 → シーン → 操作 → CFS確認 → Revision保存」です。CFS表だけを直接埋めるのではなく、原則として元タブの設定を整えます。

8. InspectionModeの運用方法

原則: InspectionModeは現地検査・指摘修正のためのモードです。開始前にDraftの扱いを確認し、終了時にRevisionへ保存して、誰がどこを変更したかを残します。

開始から完了まで

  1. CFSタブでInspectionModeを選択します。
  2. 開始ダイアログで、新しいRevisionを保存して開始、現在のRevisionのまま開始、Cancelから選びます。Draftがある場合は保存してから開始することを推奨します。
  3. 編集対象セルを選択します。Area Scene由来の値は標準でリンク対象へ反映されます。
  4. セルに重なって開く編集ボックスで値を変更します。右上は変更前の値です。
  5. OKでセル内の変更を確定、ResetでそのセルをInspectionMode開始時の値へ戻します。
  6. 必要に応じてSelect、Copy、Pasteで単一セルまたは範囲を複写します。
  7. Revert（操作バー）を使うと、そのInspectionMode全体を開始時点の状態へ戻し、InspectionModeも終了します。
  8. InspectionModeを終了し、終了ダイアログでRevision保存の有無を選びます。Save New Revision & Startで開始した場合、終了時はFinish Current Revisionのみ表示され、新規Revisionの再保存は行いません。Inspection MarksのHighlight表示は開始時と終了時に有効になります。終了時にInspectionModeで変更したセルは自動でInspection Markとして記録されます。

11. 困ったとき

トラブルシューティング一覧
状況確認対応
タブレットで開けないTABLET URL、同一ネットワーク、PC側CFS起動状態。PCのURLを再コピーし、Wi-Fi隔離やファイアウォールを確認します。
編集できない上部のView Only、他ユーザーのEditing表示。ユーザー登録後にEditを選択。別ユーザーが編集中なら終了を待ちます。
CFSで値が見えないAreas / Devices / Base Columns / Function Columnsの絞り込み、非表示列、Highlight状態。Show allを使い、元タブのCircuit / Scene / Switch設定とLink Mapを確認します。
Inspection変更を戻したいセル単位かセッション全体かを判断。セル単位は編集オーバーレイのReset、セッション全体は操作バーのRevertを使います。Revertは開始時点へ戻した後、InspectionModeを終了します。
Revisionを保存し忘れたDraft表示、Finish Editing時の確認ダイアログ。Save Revisionで保存してから終了します。
MicrosoftサインインできないMicrosoftサインイン画面へ進めない、またはCFSでアクセス拒否されます。Supabase AuthのAzure provider、リダイレクトURL、Entraテナント設定を確認します。CFS側ではAdminが対象メールアドレスを有効なViewer/Editor/Adminとして追加済みか確認します。
PDU値がPCごとに違うSettingsのVA / PDU。共有基準の3.3へ統一し、Device MasterのPDU / VAも確認します。
共有データベースへ保存できないSupabase接続を設定した環境か、接続設定が正しいかを確認。接続設定を見直してCFSを再起動します。共有ZIPには接続設定を含めないため、未設定のPCはローカルのdataフォルダーへ保存します。
毎回の終わり方: CFS確認 → 必要な検査 → Save Revision → Highlight Updatesで差分確認 → Export/共有、の順にすると履歴と検査結果を追跡できます。
