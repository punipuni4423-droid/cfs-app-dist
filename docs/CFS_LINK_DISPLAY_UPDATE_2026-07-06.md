# CFSリンク診断表示メモ（2026-07-06）

## 変更内容

- CFS関連タブの通常表示では、リンク未接続・旧参照の赤い警告バッジを表示しない。
- CFS表内のリンクエラー由来の赤い行・赤いセルの通常ハイライトも表示しない。
- Link Mapの診断ロジックは削除しない。必要な場合はLink Mapを開いて、リンク診断、警告、修復候補を確認する。

## 理由

過去データや一時的な旧参照が残っている場合、起動直後やタブ移動時に赤い警告が常時表示され、CFS確認作業の主目的である表の確認・InspectionMode操作を妨げるため。

## 維持する挙動

- CFS値生成、Area Scene、Scene、Switch、Backlight、HVACの参照解決は変更しない。
- Backlight LogicをHVACより下に出す既存仕様は変更しない。
- Link Map内の診断情報とHVAC旧リンク修復導線は維持する。
