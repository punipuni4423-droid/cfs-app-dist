# CFS App 共有手順（暫定版）

> **廃止済み（2026年7月13日）**: この文書のZIP構成・データ同梱・起動方法は現行仕様と異なります。現在の共有手順は [`../SHARE_README_JA.md`](../SHARE_README_JA.md) を参照してください。現行の共有ZIPには既存プロジェクトデータを含めません。

## 共有するもの

他の人へ渡す場合は、以下のZIPを共有してください。

- `artifacts/cfs-app-share-20260608.zip`

ZIPにはアプリ本体、現在の `data/projects.json` / `data/trash/trash.json`、ショートカット作成用の `CREATE_DESKTOP_SHORTCUT.vbs`、起動用の `LAUNCH_CFS_APP.vbs` / `START_CFS_APP.bat` が含まれます。

## 受け取った人の起動方法

1. ZIPを任意のフォルダへ展開します。
2. 展開したフォルダ内の `cfs-app\CREATE_DESKTOP_SHORTCUT.vbs` をダブルクリックします。
3. デスクトップに `CFS App` ショートカットが作成されます。
4. 以後はデスクトップの `CFS App` ショートカットから起動します。
5. 初回のみ依存関係のインストールが走ります。
6. ブラウザで `http://localhost:3014` が開きます。

フォルダ内から直接起動する場合は、`cfs-app\LAUNCH_CFS_APP.vbs` をダブルクリックしてください。

## 事前に必要なもの

- Node.js LTS
- npm
- 初回起動時のインターネット接続（依存関係をインストールするため）

Node.jsが入っていない場合は、起動時に案内を表示して止まります。

## データについて

この暫定配布では、ZIP作成時点の `data` フォルダを同梱します。

- `data/projects.json`: プロジェクト本体
- `data/trash/trash.json`: Trash/削除済みデータ

各PCで起動後に編集した内容は、そのPC内の `data` フォルダへ保存されます。複数人で同じデータを同時編集する共有サーバー構成ではありません。

## 注意

- この共有形式は暫定版です。
- 相手PCごとにローカル保存されるため、複数人の更新を自動で統合することはできません。
- 本格運用する場合は、社内サーバー、クラウド公開、またはWindowsアプリ化のいずれかを検討してください。
