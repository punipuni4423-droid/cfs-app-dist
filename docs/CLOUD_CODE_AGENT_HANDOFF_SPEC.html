1. 目的と最重要方針

CFS アプリは、ホテル/客室などの Lutron/GRMS 系の照明回路、デバイスアサイン、シーン、 スイッチ、HVAC、バックライト、CFS 統合表を一つの room type 単位で管理するための業務アプリです。 画面は Excel 由来の表入力に近いですが、単なる表ではなく、回路・デバイス・シーン・スイッチ設定を相互連動させることが目的です。

最重要: レビューや修正時に、見た目の簡略化や一般的な UI 作法を理由に、ユーザーが意図して積み上げた業務仕様を勝手に変えないでください。 特に Reserved、Uneffected、DALI、PIR/QSM、CFS 表示、PDU 数量連動は意味を持つため、単純なリファクタ対象ではありません。

この文書で Cloud Code に期待すること

  • フロントエンドの全タブをブラウザで開き、表示崩れ、リストはみ出し、文字切れ、横スクロール過多、操作不能箇所を確認する。
  • バックエンド API、保存、移行、JSON ファイルの読み書き、フォールバック挙動を確認する。
  • 型チェック、必要に応じて Playwright 監査テストを実行する。
  • 変更を入れる場合は既存 UI の意味を維持し、勝手に用語やタブ構成を変えない。

5. PDU仕様

PDU は Lutron デバイスの PDU/VA と照明器具 VA を統合して、合計 VA と必要ブレーカー数を確認するタブです。 ここで数量を変えると、対象の種類に応じて Device Assign / HVAC / Switch / 手動 PDU 数量へ反映されます。

要素仕様確認ポイント
上部 KPI Total PDU, 1 PDU = N VA, Correction, Breaker, Fixture VA, Lutron Device VA, Combined VA Fixture VA 横に DALI Included または DALI Excluded を表示する。
Lutron Device PDU Summary Device Master の pdu または watts を持つデバイスを表示。数量は source 別に連動。 Show Reserved / Hide Reserved ボタンで数量 0 の行を表示/非表示。ボタンサイズは共通。
数量 source Device Assign, HVAC, Switch, Manual アドレス設定を持つデバイスは Device Assign に展開。TSTAT は HVAC。Palladiom/Pico/PIR/QSM は Switch 系へ展開。
Lighting Fixture VA Summary Circuit と Fixture Master から fixtureUnitVa を使って集計。 Exclude DALI はチェックボックスではなくボタン。押下後は Show DALI になり、DALI 行が除外される。
Total Power Summary Lighting Fixture Total VA + Lutron Device Total VA = Combined Total VA。Breaker Rating は 20A。 Voltage と Total Current は現在表示しない。Per-Room Device Quantities 表も削除済み。

Device Master の現行デフォルト方針

  • 追加済み: MP-1L-GCU, MP-2L-GCU, GCU-HOSP, GCU-HOSP-1, QSPS-DH-1-75, Palladiom Tstat, QSM, Palladiom Keypad など。
  • 削除対象/復活禁止: HQP7-1, Wireless OCC, Pico Remote。
  • DeviceAssign で選べるのは DEVICE_ADDRESSES を持つデバイスのみ。PDU 専用/スイッチ専用デバイスを勝手に Device Assign に出さない。

6. Circuit / Device Assign

Circuit タブ

  • DALI 以外は 1 回路で複数器具がある場合、+ ボタン等の見た目は行結合される。DALI は除外。
  • pcs は Backspace 後に初期値 1 が残って 12 になる問題を避けるため、空入力を許容する。
  • Fixture Type が DL の場合は pcs を整数単位で上下。Indirect の場合は +0.1/-0.1 と +1/-1 の調整ボタンを持つ。
  • Fixture の Correction は 0.1 単位で扱う。
  • Detail には Clear ボタンがある。
  • CSV Import / CSV Export を持つ。

Device Assign タブ

  • Circuit 選択肢は、割当済みの場合 1 - MQSE-4A1-D/1 Zn1 のように回路がどのデバイス/アドレスに割り当たっているかを表示する。
  • リストでは Reserved を表示しない。Clear は Reserved と同義。
  • Hide Reserved 状態は localStorage に保持され、タブ移動後も維持する。
  • CCI の Circuit 入力時に Detail を自動入力する機能は削除された。勝手に復活させない。
  • 固定デバイスと DALI デバイスでアサインロジックが違う。DALI は line/group/address 表示を持つ。
  • Detail は Clear 可能。Reserved 行の見た目はグレー系で、入力済みと誤認しないようにする。
  • HVAC は Device Assign 内の別モード/セクションとして管理する。

7. Area Scene / Scene / HVAC

シーン値の未設定状態は UI 上 Uneffected と表示する。この綴りは現在の UI 仕様として維持する。 空文字が実データ上の未設定であり、0 やグレーの仮値で誤認させないことが重要です。

Area Scene

  • Lighting と HVAC は分離されたセクション。HVAC を Bedroom などの通常エリア内に混ぜない。
  • Lighting も HVAC 同様に最小化/最大化できる。
  • On/Off 系には On, Off, Blinking (Short), Blinking (Long), 0.5 sec, Uneffected がある。
  • 調光/パーセント系は 0%, 100%, -10, -1, +1, +10, Uneffected, Raise, Lower を扱う。InspectionModeでは終了時の確認でドラフトを反映する。
  • HVAC には Link all HVAC があり、チェック時は同じ metric の設定が全 HVAC ターゲットへ連動する。

Scene タブ

  • PMS / Door Magnet などのシーン呼び出し設定を行う。
  • Setting は別ウィンドウではなく、暗い backdrop の手前 overlay として表示する。
  • Overlay は Esc または backdrop で閉じられる。
  • Scene Value と Backlight は overlay 内のボタンで行き来できる。切り替えても上位置がずれないこと。
  • 設定が入っている Setting ボタンは色を濃く、未設定は文字が読める程度のグレーにする。
  • Area Scene を割り当てても Individual Override には値を自動コピーしない。CFS では Area Scene 値を基礎とし、Individual があれば Individual を優先する。
  • Individual OverrideはCFS上で優先表示され、HighlightsのIndividual Overrideで表示確認する。旧来の自動展開/Uneffectedのみ折りたたみ挙動には依存しない。

HVAC Season Schedule

  • 日付は編集可能。
  • 1 行目 end と 2 行目 start、2 行目 end と 3 行目 start、最後の end と 1 行目 start は 1 日違いで連動させる。
  • 行追加/削除後も日付が wrap しすぎないように正規化する。
  • HVAC assignment には thermostatRole: Master | Slave がある。CFS の Group/Zone/Address と連動する意味を持つ。

8. Switch / Command / PIR / QSM

Switch 共通

  • Switch 種別: CCI, Palladiom, Pico, PIR, QSM。
  • Palladiom/Pico はボタン数に応じて行が展開される。
  • Function行の削除とスイッチ全体の削除は列で分ける。Row列のマイナスは該当Function行、Switch列のゴミ箱はスイッチ/CCI/Palladiom/Pico/PIR全体、コピーはCopy Switchを対象にする。Switch列はスイッチ単位で行結合し、中央配置する。
  • Trigger Condition は Trigger Master から選択でき、自由入力も可能。
  • リストは画面外にはみ出さないよう portal/fixed positioning を使う。外側クリックで閉じる。

PIR

  • PIR タブ上部に PIR Registration 表がある。ここで Area ごとに PIR の数量を登録する。
  • Area Scene に出ていないエリアにも PIR がある可能性があるため、すべての Area から登録できる。
  • 登録された PIR は連番表示 PIR1, PIR2... を持つ。セル内で PIR13 のような紛らわしい結合表示を作らない。
  • 下のロジック表では、登録済み PIR から複数選択できる。Location 列でどの場所か分かるようにする。
  • CFS 上では PIR 番号と Location を表示する。複数 PIR が絡む場合は summary + 展開 UI で見せる。

QSM

  • QSM は PIR に紐づくレシーバー。QSM タブで QSM 行を追加/削除する。
  • PIR 1 台につき QSM は必ず 1 台に紐づく。複数 QSM へ同時割当は不可。
  • 片方の QSM に PIR をチェックしたら、他方の QSM からは外れる OR 条件。
  • 全 PIR はいずれかの QSM に割り当てられている必要がある。未割当が生じた場合は先頭 QSM などに正規化する。

Command

  • Command タブの Switch 選択肢に UUID のような不明値を表示しない。
  • 表示名は switch number/name/button/condition など、ユーザーが理解できる値に整形する。

Backlight

  • 複数 Palladiom がある場合に 1 つだけに潰れないこと。
  • Scene タブの Backlight setting と Switch 側の UI は共通思想で扱う。
  • Palladiom Backlight Assignment は未設定時に By Scene を既定として扱い、Uneffected は選択肢に出さない。
  • Backlight Logic は CFS で HVAC より下に表示し、同じスイッチ/ターゲットで重複行を作らない。

9. CFS統合ビュー

CFS は最終確認/Excel 出力に近い統合ビューです。Circuit, Device Assign, Area Scene, Scene, Switch, Command, Backlight, HVAC の値を統合して表示します。

機能仕様意図
Toolbar Base, Function, Device, Area, Display, Programming Name, Highlights, Excel Export, Maximize 項目が増えたため、表示設定はメニューにまとめる。ボタン高さは揃える。
Sort Device / Area / Internal # / Programming Name ソート Internal # と Programming Name ソートを入れている。削除しない。
Display Number Display, Area Scene Name 表示, Area Scene Highlight 表示を切替 Area Scene 名やハイライトは必要に応じて表示/非表示できる。

表示文字 Slash 区切りを 2 行表示する場合は不要な slash/colon を出さない 文字が潰れないようにしつつ、意味が重複しない表示にする。

10. Settings / Master

Settings は /settings/devices にある。共有 App Settings として全プロジェクトに効く。

  • Device Master: device model/control/abbrev/lowEnd/highEnd/addressMode/PDU/VA を管理する。
  • デフォルト行の model/control/addressMode は基本的に業務上の意味がある。編集可否は現状コードに従う。
  • PDU/VA 値は編集可能。VA / PDU も直接入力可能。
  • Input Master: CCI/Input 系の Detail/入力候補に使う。
  • Trigger Master: Trigger Condition の候補に使う。ただし自由入力も可能。
  • Display: 表示倍率、Admin Mode、CFS Link Mapの表示許可。
  • Link Map入口は通常非表示。SettingsのDisplayでAdmin ModeをONにしたうえで、CFS Link MapをONにした場合だけCFSタブへ表示する。Linked Values塗りつぶしは2026-08-25に廃止済み。

11. 共通UIルール

Reserved

Reserved は未割当/クリア状態。リスト上には基本表示しない。Clear 操作で Reserved に戻す。

Uneffected

シーン値の未設定表示。空文字を意味する。Unaffected へ勝手に改名しない。

Dropdown

リストは portal/fixed 表示で画面内に収める。外側クリックと Esc で閉じる。複数リストが残らないようにする。

Keyboard

Ctrl + Arrow で表内の上下左右セルへ移動。Select/Combobox は上下キー単独で候補移動できる。

Buttons

Show/Hide Reserved, Exclude/Show DALI などは共通ボタンサイズで、位置を揃える。

Item count

14 items のような汎用件数表示は削除済み。PIR 登録数など意味のある badge は残してよい。

12. バックエンド/保存

API

EndpointMethod内容制約
/api/projects GET data/projects.json から読み込み、migration 済み projects を返す。 ファイルなしなら空配列。
/api/projects POST payload の projects を検証/migration し、atomic-ish に tmp から rename 保存。 最大 10MB。invalid JSON は 400。
/api/trash GET/POST Trash projects/roomTypes を data/trash/trash.json に保存。 最大 10MB。空/ファイルなしは empty trash。

フロント保存フロー

  • 起動時は DB/API から projects/trash を取得する。
  • 10 秒 timeout または API 失敗時は localStorage backup を読む。
  • projects は 1200ms debounce で API 保存し、Saving..., Saved at, Save failed を表示する。
  • trash は 300ms debounce で保存する。
  • Import/Export は JSON backup 形式にも対応する。

14. レビュー観点

フロントエンド

  • 表内の text/button/select/input が親幅に収まり、見切れ・重なりがない。
  • タブ切替後に scroll position が変に飛ばない。
  • Overlay は固定サイズ/上位置の安定性を保ち、内容だけスクロールする。
  • Setting ボタンの有無状態が色で判別できる。
  • Reserved/DALI/PIR/QSM/HVAC の特殊表示が壊れていない。
  • Ctrl + Arrow ナビゲーションが button/select/input/textarea で破綻しない。
  • ブラウザ console に key warning や hydration error が出ていない。

バックエンド

  • GET/POST /api/projects が JSON を正しく read/write し、invalid payload を拒否する。
  • GET/POST /api/trash が空ファイル/ファイルなし/invalid payload に耐える。
  • 保存中に bar/toolbar のサイズが変動しない。
  • migration が既存データを落とさない。特に pduDeviceCounts, switchGroupId, roomScenes, hvacSeasons, thermostatRole。
  • App Settings は localStorage だが、Device Master の default merge/remove ルールを守る。

15. 勝手に変えないこと

エージェント向け注意: 一見すると表記ゆれや冗長 UI に見える箇所でも、ユーザーとのやり取りで業務意図が定まっているものがあります。
  • Uneffected 表記を勝手に変えない。
  • Reserved を dropdown に戻さない。Clear = Reserved の考え方を維持する。
  • PDU の Exclude DALI をチェックボックスに戻さない。ボタン方式が正。
  • PDU の Per-Room Device Quantities 表を復活させない。
  • PDU タブを CFS の後ろへ戻さない。左端が正。
  • Device Assign の CCI detail 自動入力を復活させない。
  • PIR の area registration と logic selection を一つの表に戻さない。
  • QSM の PIR 割当を複数 QSM 同時選択可能にしない。
  • CFS の Area Scene 名/ハイライト表示切替を消さない。
  • Backlight Logic を HVAC より上に戻さない。
  • Default Device から削除済みの HQP7-1, Wireless OCC, Pico Remote を戻さない。
  • 汎用 items 件数表示を復活させない。ただし PIRs など意味のある badge は別。
